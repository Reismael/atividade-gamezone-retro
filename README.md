# 🎮 GameZone Retro

## 📋 Sobre o Projeto

Este projeto foi desenvolvido como parte do **Mini Desafio HTML - Loja de Games Retro**.

A proposta foi criar uma página simples e funcional para uma loja fictícia chamada **GameZone Retro**, utilizando apenas **HTML puro**, sem CSS ou JavaScript.

A página apresenta consoles clássicos, jogos e seus respectivos preços, além de links e uma imagem relacionada ao tema.

## 🎯 Objetivo

Praticar os principais conceitos de **HTML**, criando uma página com:

- Títulos e parágrafos
- Textos em **negrito** e *itálico*
- Lista de consoles
- Link interno
- Link externo
- Imagem
- Tabela de produtos e preços

## 🕹️ Conteúdo da Página

A GameZone Retro apresenta alguns consoles clássicos:

- Nintendo (NES)
- Super Nintendo (SNES)
- Sega Genesis
- Atari 2600

Também possui uma tabela com alguns jogos:

| Jogo | Console | Preço |
|---|---|---:|
| Super Mario Bros | NES | R$ 85,00 |
| Sonic | Genesis | R$ 70,00 |
| Zelda | NES | R$ 120,00 |

## 🔗 Links

A página possui:

- **Link interno:** direciona o usuário para a seção de preços.
- **Link externo:** direciona para o Instagram.
